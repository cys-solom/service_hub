# 🖼️ دليل رفع صور المنتجات (اللوجوهات)

## كيف تحصل على لينك صورة لاستخدامه كلوجو منتج في لوحة الأدمن

---

## الطريقة 1: ImgBB (الأسهل والأسرع) ⭐

1. ادخل على [imgbb.com](https://imgbb.com)
2. اضغط **"Start Uploading"**
3. اختار الصورة من جهازك
4. بعد الرفع، اضغط على **"Direct link"** أو **"Image URL"**
5. انسخ اللينك (المنتهي بـ `.png` أو `.jpg`)
6. الصقه في خانة **Product Image** في لوحة الأدمن

**مثال للينك:**
```
https://i.ibb.co/abcdef/chatgpt-logo.png
```

> ⚠️ **ملاحظة:** لا تستخدم لينك الصفحة (اللي بيبدأ بـ `https://ibb.co/...`)، استخدم **Direct Link** فقط اللي بينتهي بامتداد صورة.

---

## الطريقة 2: Postimages (بدون حساب)

1. ادخل على [postimages.org](https://postimages.org)
2. اضغط **"Choose images"** وارفع الصورة
3. من القائمة اختار **"Direct link"**
4. انسخ اللينك والصقه في لوحة الأدمن

**مثال للينك:**
```
https://i.postimg.cc/abcdef/logo.png
```

---

## الطريقة 3: GitHub (مجاني ودائم) ⭐⭐

### طريقة سريعة (من المتصفح):
1. افتح أي Issue في أي ريبو على GitHub
2. اسحب الصورة وحطها في مربع الكتابة (drag & drop)
3. GitHub هيرفعها تلقائياً ويديك لينك
4. انسخ اللينك اللي بيبدأ بـ `https://github.com/user-attachments/...`
5. مش لازم تبعت الـ Issue، بس انسخ اللينك وامسح

### طريقة منظمة (داخل الريبو):
1. روح للريبو: `https://github.com/cys-solom/service_hub`
2. ادخل مجلد `public/logos/`
3. اضغط **"Add file"** → **"Upload files"**
4. ارفع ملف الصورة (يفضل SVG أو PNG)
5. اضغط **"Commit changes"**
6. اللينك هيكون: `/logos/اسم-الملف.svg`

---

## الطريقة 4: Imgur

1. ادخل على [imgur.com](https://imgur.com)
2. اضغط **"New post"** → ارفع الصورة
3. اضغط كليك يمين على الصورة → **"Copy image address"**
4. الصق اللينك في لوحة الأدمن

**مثال للينك:**
```
https://i.imgur.com/abcdef.png
```

---

## الطريقة 5: Cloudinary (احترافي - مجاني حتى 25GB)

1. سجل حساب مجاني على [cloudinary.com](https://cloudinary.com)
2. من الداشبورد اضغط **"Upload"**
3. ارفع الصورة
4. انسخ الـ **URL** من تفاصيل الصورة
5. الصقه في لوحة الأدمن

**مثال للينك:**
```
https://res.cloudinary.com/your-cloud/image/upload/v123/logo.png
```

---

## ⚠️ نصائح مهمة

1. **استخدم دائماً Direct Link** - اللينك المباشر للصورة (ينتهي بـ `.png`, `.jpg`, `.svg`, `.webp`)
2. **لا تستخدم لينك الصفحة** - مثل `https://ibb.co/xyz` - ده مش هيشتغل
3. **يفضل صور PNG أو SVG** - لأنها بتدعم الشفافية وبتظهر أحسن
4. **حجم الصورة المثالي:** 200x200 بكسل أو أكتر (مربعة)
5. **SVG هو الأفضل** - لأنه خفيف وبيتكبر بدون ما يبوظ

## 🎯 الخطوات في لوحة الأدمن

```
1. روح: /admin → Products
2. اضغط "Edit" على المنتج أو "New Product"
3. في خانة "Product Image" 🖼️ حط اللينك
4. هتشوف preview للصورة فوراً
5. اضغط Save ✅
```
